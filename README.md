Entry for the [One Line, One Chill](https://make.fun) competition on make.fun.

## What it does

`main.ts` writes a single horror sentence — 116 characters, one line,
one sentence — to `/output/entry.txt`. The line is assembled
deterministically from three beats (an ordinary image, an impossible
voice, a twist), then checked against the gate (1–200 characters,
single line, exactly one sentence) before it is written.

> The baby monitor plays my lullaby back to me every night in my
> mother's voice, and my mother died before I was born.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
